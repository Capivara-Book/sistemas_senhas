# Sistema de Distribuição de Senhas

Implementação de um sistema em C para gerenciamento de filas e distribuição de senhas (comuns e prioritárias), desenvolvido para a disciplina de Paradigmas de Programação. O projeto inclui controle de chamadas (FIFO), histórico de tempos de atendimento e uma suíte completa de testes automatizados.
